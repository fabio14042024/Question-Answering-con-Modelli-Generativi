# Question-Answering-con-Modelli-Generativi

• Obiettivo: Confronto di metodologie di Question Answering (QA) con modelli generativi. 

• Modelli e Dataset: Valutazione comparativa di Gemma 3 (4B) e Qwen 3 (4B) su sotto-domini del dataset SQuAD (Stanford Question Answering Dataset).

• Metodologie: Zero-Shot Prompting, In-Context Learning e Web Search Agent (con DuckDuckGo).  

• Valutazione: Misurazione delle prestazioni (Exact Match, ROUGE, METEOR, In-Text, BLEU) e analisi di significatività tramite test statistici.  

• Risultati: Superiorità dell'In-Context Learning: l'accuratezza delle risposte generate dipende strettamente dall'alta pertinenza del contesto fornito
